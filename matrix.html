1. Purpose & Scope

The purpose of this standard is to establish a unified framework for classifying data assets based on their sensitivity, value, and criticality to Vadom Data Consulting SAS. This classification drives the implementation of appropriate security controls, access restrictions, and handling procedures.

2. Classification Matrix

Level Definition Data Examples Required Controls
LEVEL 1
PUBLIC		 Information approved for public release. No risk.
  • Marketing Materials
  • Public Website Content
  • Terms of Service
 • Access: Unrestricted
• Encryption: Standard HTTPS
• Labeling: None
LEVEL 2
INTERNAL		 Restricted to employees. Minor disruption risk.
  • Employee Handbooks
  • Internal Policies
  • Departmental Memos
 • Access: Authenticated Users
• Storage: Corporate Drive
• Sharing: Internal only
LEVEL 3
CONFIDENTIAL		 Sensitive info. Financial/reputational loss risk.
  • Client Proposals & Contracts
  • Source Code
  • Network Diagrams
 • Access: Role-Based (RBAC)
• Transit: TLS 1.2 Encrypted
• Legal: NDA Required
LEVEL 4
RESTRICTED		 Highly sensitive. Severe fines/breach risk.
  • Customer PII (IDs, Phones)
  • Financial Data (Bank Accts)
  • Production API Keys
  • Background Checks
 • Access: Need-to-Know (Admin)
• Auth: MFA Mandatory
• Storage: AES-256 Enc.
• Audit: Full Logging
