1. Resumen Ejecutivo

El presente documento certifica que la infraestructura tecnológica que soporta la plataforma de Vadom Data Consulting, alojada en la nube de Amazon Web Services (AWS), opera bajo un modelo de Seguridad Gestionada (Managed Security Services) administrado por Advancit SAS.

Nuestro equipo de ingeniería cloud realiza labores continuas de monitoreo, actualización y endurecimiento (hardening) de los sistemas, garantizando la confidencialidad, integridad y disponibilidad de los datos procesados, en cumplimiento con el AWS Well-Architected Framework.

2. Alcance del Servicio de Seguridad

La gestión de seguridad abarca los siguientes componentes críticos del entorno productivo:

  • Capa de Red: Configuración de VPC, Subredes Privadas/Públicas, y Firewalls Virtuales (Security Groups / NACLs).
  • Capa de Cómputo: Gestión de parches de seguridad a nivel de Sistema Operativo (Linux Ubuntu) en instancias EC2.
  • Capa de Datos: Encriptación y respaldo de Bases de Datos Gestionadas (Amazon RDS PostgreSQL) y Almacenamiento de Objetos (S3).
  • Gestión de Identidades: Control de accesos privilegiados (IAM) y rotación de credenciales.

3. Metodología de Evaluación y Control

A diferencia de una auditoría puntual, Vadom Data cuenta con un esquema de Cumplimiento Continuo, donde se ejecutan las siguientes actividades periódicas:

  • Análisis de Vulnerabilidades: Escaneo automatizado mediante AWS Inspector y AWS Trusted Advisor para detectar configuraciones inseguras.
  • Gestión de Parches (Patch Management): Aplicación de actualizaciones críticas en un plazo no mayor a 48 horas tras su liberación.
  • Monitoreo de Amenazas 24/7: Vigilancia activa de logs mediante Amazon CloudWatch para detección de intrusiones.
  • Resiliencia y Backups: Verificación diaria de integridad de Snapshots y replicación Multi-AZ.

5. Conclusión y Dictamen Técnico

Advancit SAS certifica que la plataforma de Vadom Data Consulting cuenta con una arquitectura robusta y segura, diseñada para mitigar riesgos cibernéticos modernos. Los controles implementados son suficientes y adecuados para el procesamiento de información sensible y confidencial.

El entorno se encuentra OPERATIVO y SEGURO, sin hallazgos críticos pendientes de remediación al momento de esta certificación.
